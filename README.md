🔗 **Live Demo:** [saravana022.netlify.app](https://saravana022.netlify.app/)

---

## ✨ Features

- 🌓 **Dynamic Theme Switching**: Seamlessly toggle between dark and light modes.
- 🎭 **Smooth Animations**: Intersection Observer based fade-up and scale-in effects for a premium feel.
- 🌌 **Particle Background**: Interactive particle effects that react to user engagement.
- 📱 **Fully Responsive**: Optimized for all screen sizes (mobile, tablet, desktop).
- 🛠️ **DevOps Focused**: Dedicated sections for Skills, Projects, Experience, and Certifications.

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/saravana022/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run in development mode**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 🌐 Deployment
